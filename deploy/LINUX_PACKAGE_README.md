# Linux x64 personal package

This unsigned package targets **Debian 13 x64 / glibc 2.41**. It contains Electron 44.3.0 and the application, plus Node 22.23.2, FFmpeg/ffprobe 9.0.1, yt-dlp 2026.08.19, the native tools' ELF library dependencies, DejaVu Sans and CA certificates. It needs no global Node or FFmpeg installation. Keep the entire extracted directory together.

Run `./run-headless` to start the standalone backend. It defaults to loopback `http://127.0.0.1:4319`; set `MW_DATA_DIR` to a private writable directory. Read its owner token from the named credential file. The command invokes only the packaged Node/tools. Native wrappers set their own library, font and CA paths. The system `/bin/sh`, Debian 13 ELF loader, kernel and standard OS configuration remain required; this is not a universally portable glibc bundle.

`./media-workbench` is the Electron desktop entry point. **Desktop launch, display, clipboard, drag out and Linux desktop integration remain untested.** A graphical Debian 13 session and Electron's normal GTK/NSS/GBM/ATK/X11-or-Wayland system dependencies are required. Do not disable Chromium's sandbox to work around installation issues. Browser/headless tests do not establish desktop support.

Build using `docker build --target linux-artifact --output type=local,dest=release .`. The existing Dockerfile pins the official Node image, Debian snapshot libraries, verified FFmpeg source and official yt-dlp hashes. `scripts/package-linux.mjs` verifies the official Electron release archive through `@electron/get`, records its digest, inventories every packaged tool/library hash, and retains tool provenance under `resources/app/provenance`. The tar archive preserves executable permissions; on Linux extract it with `tar -xzf media-workbench-linux-x64-debian13.tar.gz`.

Bundled reports are snapshots taken when packaging began. `resources/app/provenance/linux-package.json` identifies this bundle's source and native-tool hashes. The external `release/linux-package-evidence.json` and final smoke-test evidence are authoritative for the archive checksum and final verification results; an archive cannot contain its own final checksum. The internal README's linked API, status, review, final report and handoff documents are included under `resources/app/docs`.

The original application is MIT. Bundled FFmpeg enables GPL codec libraries; Node, Electron, yt-dlp, fonts and ELF dependencies retain separate licenses. The package retains the FFmpeg source/configuration, Debian package/source-version inventory and copyright notices, Node and yt-dlp licenses, plus Electron's release notices. Other dependencies' complete corresponding source is not bundled. **This is a personal local build, not an approved public redistribution, signed release or verified universal Linux desktop package.** Review the exact binary closure and corresponding-source obligations before distribution.
