## Milestone evidence and remaining release gates

M0 and M1 are runnable foundations/download-to-output slices with real tools, immutable imports, durable batches/history, playback and native Windows file copy. M2 has Windows19/19 and Linux23/23 media/process checks plus independent decoded identities and edited browser output. M3 has actual isolated shared API, filesystem/egress/resource/cancellation tests; the tests cover the synthetic deployment profile, not an untested public host. M4 has a clean Windows source-install proof and packaged dependency proof; see the Linux packaging report for its measured scope.

Final broad default command after lifecycle, active cancellation and global auxiliary-cap changes: `npm test` reported 86 tests, 71 passed, 0 failed, 15 explicitly skipped in 231.28 seconds. The final diagnostic-only change has an additional passing real-child regression in `tests/security-diagnostics.test.ts`, independently rerun by the reviewer, and typecheck passed. Docker, native and live-site suites were run separately with their opt-in flags; a default skip is not a failure or an assertion that those opt-in runs passed. The final verification report records commands and separate opt-in evidence.

Environment blocker: the final Linux archive refresh did not complete. The prior verified archive is preserved. Docker is stopped after a stale runtime AF_UNIX socket prevented restart; reversible quarantine failed and automatic approval review rejected exact socket removal. Windows's final package passed its full native smoke after disk recovery. Source, final Windows package and prior Linux package status are deliberately recorded separately.

Remaining platform/integration evidence: Linux desktop environments, physical hardware encoders/driver changes, ARM64, native drag/compose receivers, browser-cookie extraction, installed ShareX result integration, public TLS/reverse-proxy operation and rootless/Linux-controller isolation. Release blockers are signing and complete redistribution/corresponding-source review of the chosen native bundles. Unsupported HDR transforms fail explicitly. These limits do not turn the tested local workflows into mock implementations, and they do not justify claiming a completed public stable release.
